# Trademark Policy

## 1. Purpose

This document outlines the policy regarding the use of the name **"Compressor"**, the project logo, and related visual branding assets. The objective is to encourage community development and distribution while ensuring that users know they are running genuine, unmodified software.

---

## 2. Permitted Uses

You may freely use the name to:
- Reference the official open source project in articles, tutorials, discussions, and benchmark comparisons.
- Distribute unmodified binary releases or packages (e.g. Homebrew, Scoop, Arch AUR, Debian packages).
- Link to the official GitHub repository and documentation.

---

## 3. Restricted Uses

Without prior written permission from the project maintainers, you may **not**:
- Use "Compressor" as the primary name of a commercial product or proprietary fork in a manner that implies official endorsement.
- Alter the logo or visual assets in confusing ways for commercial software.
- Register domain names containing the exact mark in bad faith.

---

## 4. Derived & Modified Software

If you distribute a heavily modified version or fork of Compressor:
- You must make it clear that your fork is not the official upstream Compressor project.
- You must provide attribution according to the terms of the MIT License.
